# Чат-бот с ИИ для ВКонтакте и Telegram

Учебный проект по реальному заказу с FL.ru: ИИ-консультант налоговой компании, который отвечает по базе знаний, ведёт клиента к записи на консультацию и сообщает владельцу о новой записи.

Компания «Налоговая гавань», услуги, цены и расписание вымышлены.

## Как это работает

```text
клиент (ВКонтакте или Telegram)
   -> канал (Long Poll / aiogram)
   -> ядро диалога: память, база знаний, системный промпт
   -> нейросеть через ProxyAPI (модель gpt-4.1-mini)
   -> функция записи: проверка времени, дублей и занятых слотов
   -> уведомление владельцу в Telegram + строка в Google Таблице
```

- Один движок диалога на оба канала. Канал только принимает и отправляет сообщения.
- Запись оформляется функцией `create_booking`. Бот вызывает её только после явного «да» клиента. Правила проверяет код, а не модель: рабочие дни, время 10:00–18:30 по Москве, шаг 30 минут, минимум за час, занятые слоты, дубликаты.
- В ответах нет Markdown: он остаётся в мессенджере лишним мусором.
- Ограничения: не больше 8 сообщений в минуту от одного человека, длина сообщения до 1000 символов, история диалога 12 реплик.

## Состав

```text
app/main.py             запуск каналов
app/config.py           настройки из переменных окружения
app/core/brain.py       движок диалога и функция записи
app/core/booking.py     правила записи
app/core/llm.py         клиент ProxyAPI
app/core/memory.py      SQLite: история и записи
app/core/notify.py      уведомления владельцу
app/channels/vk.py      ВКонтакте, Long Poll API
app/channels/tg.py      Telegram, aiogram
kb/                     база знаний (company, services, faq, rules)
prompts/system.md       системный промпт
prompts/greeting.txt    приветствие
tests/                  проверки
deploy/                 установка службы systemd
```

Чтобы сменить компанию, достаточно заменить файлы в `kb/`, `prompts/` и при необходимости часы приёма в `app/core/booking.py`.

## Настройки

Секреты лежат только в переменных окружения, в репозитории их нет. Названия перечислены в `.env.example`.

## Проверки

```bash
python -m tests.test_unit      # правила без интернета
python -m tests.scenarios      # семь диалогов с настоящей нейросетью, уведомления отключены
```

## Запуск на сервере

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m app.main
sudo bash deploy/install_service.sh    # как постоянная служба
```

Служба ограничена по памяти (300 МБ) и сама перезапускается после сбоя.

## Безопасность

- Ключи и токены не попадают в код, журнал и репозиторий.
- Бот не просит паспортные данные, номера карт и пароли.
- Инструкции в промпте защищают от смены роли. Реальные последствия ограничены кодом: даже если модель «согласится», запись с неверным временем не создастся.
